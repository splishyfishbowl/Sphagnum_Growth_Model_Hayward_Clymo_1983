# Sphagnum_Growth_Model_Hayward_Clymo_1983
This is the code that I wrote to implement the Sphagnum growth model by Hayward and Clymo (1983).
I used Python 3.12. to run the files. 

The essential Model classe are
- Envionment.py
- Map.py
- Growth_Processes_Model.py
- Plant.py
- Simulation.py

All the other files are either to make Figures, Plots or makes the CSV data ready.
